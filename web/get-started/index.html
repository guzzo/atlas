MAKE YOUR FIRST CONNECTION

From local agent to verifiable request.

CODEX + MCP

Use this checkout, Docker Compose and your local Codex instance. Three steps to see it work.

  1. 01

    Start your workspace.

    Run from the repository. This starts the services and enrolls codex-local. Already running? Continue to step 2.

    TERMINAL · REPOSITORY ROOT 
    ./bin/dev
  2. 02

    Connect it to Codex.

    Run this helper, then run the codex mcp add command it prints. Restart Codex and check the connection with /mcp.

    TERMINAL · REPOSITORY ROOT 
    ./bin/passport connect codex-local
  3. 03

    Ask for the evidence.

    Use this prompt in Codex. It checks identity and authorization, then returns a verification trace without executing the purchase.

    YOUR CODEX CONVERSATION

    Verify my Passport identity, then verify a 1200-cent Globex purchase with a private proof. Show the verification trace without executing the purchase.

✓ The result: a verified request and a signed authorization receipt.See your receipts ↗
Another agent, or an expired key?

Give each runtime its own identity. From the repository, run:

./bin/passport enroll codex-researcher
./bin/passport connect codex-researcher

Runtime credentials last 24 hours. Renew with ./bin/passport renew codex-local, then restart the MCP connection. With private proofs disabled, leave “with a private proof” out of the prompt.
